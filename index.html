Why learn R?

Two things R does that a spreadsheet cannot

Before any explanation: drag the first picture, and look at how the second is made.

drag to rotate · arrow keys work too
healthy early disease late disease

Every dot is one patient, placed by about twenty thousand gene measurements squashed down to three numbers. Drag it. The two disease groups start sitting on top of one another and come apart as you turn the cloud — which is exactly why this one has to be three-dimensional, and why it has to move.

3D earns its place here because you are hunting for clusters in a cloud. On a bar chart or a pie chart it only distorts what you are trying to read, and Excel will happily let you make one. The calculation is a single line, prcomp(genes); drawing it takes about ten more. This one is drawn for the page in JavaScript, not by R — JavaScript is the only language a browser runs, and R makes the same kind of interactive figure from one command.

One R script made all of this — the map, the four charts, and the layout that joins them into one picture. The colours are written down once and handed to both halves, so a country is the same colour wherever it turns up.

Excel can colour a map. What it cannot do is tie that map's colours to four separate charts, or combine the five into a single figure — that part is done by hand, again, every time the numbers change.

# Runs as-is: it fetches the map itself, numbers are below.
# tidyverse = data handling + ggplot2, sf = map shapes,
# patchwork = sticks finished plots together.
for (pkg in c("tidyverse", "sf", "patchwork"))
  if (!requireNamespace(pkg, quietly = TRUE))
    install.packages(pkg)

library(tidyverse); library(sf); library(patchwork)

# one palette, handed to BOTH halves of the figure
pal <- c("United States" = "#3A46A8", "India" = "#B4741A",
         "Brazil"        = "#0E7A66", "China" = "#A8326B")

growth <- tibble(
  year    = rep(2005:2024, times = 4),
  country = rep(names(pal), each = 20),
  gdp_growth = c(
    # United States
    3.5, 2.8, 2.0, 0.1,-2.6, 2.7, 1.6, 2.3, 2.1, 2.5,
    2.9, 1.8, 2.5, 3.0, 2.5,-2.2, 6.1, 2.5, 2.9, 2.8,
    # India
    9.3, 9.3, 9.8, 3.9, 8.5,10.3, 6.6, 5.5, 6.4, 7.4,
    8.0, 8.3, 6.8, 6.5, 3.9,-5.8, 9.1, 7.2, 8.2, 6.5,
    # Brazil
    3.2, 4.0, 6.1, 5.1,-0.1, 7.5, 4.0, 1.9, 3.0, 0.5,
   -3.5,-3.3, 1.3, 1.8, 1.2,-3.3, 5.0, 3.0, 2.9, 3.4,
    # China
   11.4,12.7,14.2, 9.7, 9.4,10.6, 9.6, 7.9, 7.8, 7.4,
    7.0, 6.8, 6.9, 6.7, 6.0, 2.2, 8.4, 3.0, 5.2, 5.0))

url <- paste0("https://raw.githubusercontent.com/",
              "nvkelso/natural-earth-vector/master/",
              "geojson/ne_110m_admin_0_countries.geojson")
world <- read_sf(url)

# The map says "United States of America", our table says
# "United States". Making two sets of names agree is the
# commonest real data job there is. Here it is one line.
world$country <- recode(world$ADMIN,
  "United States of America" = "United States")

map <- ggplot(world) +
  geom_sf(aes(fill = country), colour = "grey85") +
  scale_fill_manual(values = pal, na.value = "grey88",
                    guide = "none") +
  coord_sf(crs = "+proj=robin") +
  theme_void()

lines <- ggplot(growth,
                aes(year, gdp_growth, colour = country)) +
  geom_hline(yintercept = 0, linetype = "dashed") +
  geom_area(aes(fill = country), alpha = 0.15) +
  geom_line(linewidth = 0.8) +
  facet_wrap(~ country) +          # four panels, one line
  scale_colour_manual(values = pal, guide = "none") +
  scale_fill_manual(values = pal, guide = "none") +
  labs(x = "year", y = "GDP growth / % per year") +
  theme_minimal()

map + lines                        # patchwork joins them
ggsave("figure.png", width = 11, height = 4.5)

You are not expected to understand this yet. Notice only two things. The palette is written once and used by both plots, which is why the map and the lines can never drift out of agreement. And map + lines is the entire layout step — you add two pictures together the way you would add two numbers.

Roughly 53 lines of R — about half of them the twenty years of numbers. Expandable above; it runs as it stands. Map: real Natural Earth outlines, Robinson projection. The copy above is drawn into this page; the R in the expander is genuine and makes the same figure. The growth figures follow the real pattern but are illustrative.

Each of those is one script. Nothing was clicked, dragged or nudged into place by hand, and running the script again next year gives back the identical picture with the new numbers in it.

How R runs here

  • Nothing to install. R runs inside this page, on your computer or Chromebook.
  • The first visit takes about 20 seconds. The page downloads R (about 40 MB) once. After that it starts in a few seconds.
  • Your data stays with you. A spreadsheet you open is read on your computer. It is never uploaded anywhere.
  • Your progress is saved in this browser. Use the same computer and browser next time.
  • For your IA or EE, you will want R on your own computer too. The starch course shows you how: install R and RStudio, then run the same script.
