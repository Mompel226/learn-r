# Learn R

**Live (when published):** https://nlcsbiology.com/learn-r/

Learn R, the language scientists use for data, with **real R running in the browser**
([webR](https://docs.r-wasm.org/webr/)): nothing to install, and nothing a student types or opens
leaves their computer. Three courses, one look:

- **Year 8 · Variation in our class** — measure the class, then summarise, graph and compare two groups.
- **IB Biology · Statistics in R** — the p-value, the normal distribution, SD and SE, then χ², the t-test
  and correlation, each told click by click before it is done in R.
- **IB Biology B1.1 · Starch curves in R** — the calibration curve from the starch practical: average,
  choose the straight part, fit the line, read R², read off unknowns; in the browser, or download the
  script for RStudio.

Stages open one at a time: the next opens when the tasks of the one before are done. Progress is saved in
the student's browser.
